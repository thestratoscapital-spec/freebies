# 🎙️ TWIN: VoiceStudio, the free open-source voice studio

You commented **TWIN**. Here's the official link, the easiest way to install it, and the one license check to do before you use it for money.

---

## The official link

👉 **[github.com/debpalash/VoiceStudio](https://github.com/debpalash/VoiceStudio)**

Use this link. Copycat sites with similar names exist, so always start from the GitHub page above.

---

## What it does

- **Clone your voice** from a short, clean recording (a few seconds is often enough)
- **Type, and it speaks** in that voice: clips, stories, whole audiobooks
- **Design new voices** that don't exist by describing them
- **Dub videos** into other languages, timed to the original
- **Transcribe and dictate** speech back into text
- **646 languages**, according to the project
- **Runs on your own computer.** No subscription, and your recordings stay on your machine

---

## Install it (easiest way)

1. Open the [**latest release**](https://github.com/debpalash/VoiceStudio/releases/latest) page.
2. Download the installer for your computer:
   - **Windows 10/11:** the `.exe`
   - **Mac (Apple Silicon, M1 and newer):** the `.dmg`
   - **Linux:** the `.AppImage` or `.deb`
3. Install it and open VoiceStudio. It asks before it downloads any voice model.

**No graphics card?** It still works on a normal CPU, just slower. An NVIDIA GPU (or a Mac with Apple Silicon) makes it much faster.

The project's README also lists one-line install commands for the terminal and a Docker image, if you prefer those. Copy them from the official README only.

## ⚠️ The thing nobody tells you: check the license

- **The app** is open source (AGPL-3.0), and that license allows commercial use under its terms.
- **The voice models are separate.** Each one has its own license. The default engine is powered by **k2-fsa/OmniVoice**, whose pretrained weights are licensed **CC BY-NC: non-commercial**.
- **If you make money from your content** (sponsored videos, ads, client work), open the **Model Manager** in the app, check each model's license, and pick one that allows commercial use.

---

## 🤝 Clone responsibly

Only clone **your own voice**, or a voice whose owner has given you permission. The project itself says the same.

---

## Quick start: your first cloned voice

1. Record **5–10 seconds** of yourself talking normally, in a quiet room, with no music.
2. In VoiceStudio, open voice cloning and add that recording.
3. Type a sentence and generate.
4. Not quite you? Try a cleaner recording. Quality in = quality out.
