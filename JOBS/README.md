# 💼 JOBS: the free AI job hunter that tells you which jobs to skip

You commented **JOBS**. Here's **career-ops**, a free, open-source job search system by **@santifer** that runs inside Claude Code.

👉 **The link:** https://github.com/career-ops-hq/career-ops

The creator's own run: **740 jobs looked at, 68 applied, 12 interviews, 1 offer.** He got the job, then open-sourced the tool.

---

## Install it (pick one)

**Easiest: one command** (needs [Node.js](https://nodejs.org))

```bash
npx @santifer/career-ops init
```

This makes a `career-ops` folder. Open it in Claude Code and just chat: it walks you through setup the first time.

**In the Claude desktop app (Code tab):**

Open **Customize → Plugins**, add the `career-ops-hq/career-ops` marketplace, install **career-ops**, then start a new session in the **Code** tab and paste a job link.

**In Claude Code (terminal):**

```
/plugin marketplace add career-ops-hq/career-ops
/plugin install career-ops@career-ops
```

> It works in the **Code** tab and Claude Code only, not in regular Chat.

---

## How to use it

1. **Give it your real CV** during setup.
2. **Paste any job post** (a link or the text).
3. It **checks the job is still open**, then **scores it 1 to 5** against your CV.
4. **Under 4.0? It tells you to skip it.** You can still overrule it, and it'll tell you that too.
5. For jobs worth it, it **rewrites your CV for that job**, **drafts the answers for every field on the form**, writes a **cover letter**, and **finds the person to message** (with a short note).
6. **You read everything and send it yourself.**

---

## Good to know

- **It never presses Submit and never sends an email.** It drafts; you decide and send.
- **Your files stay on your computer.** Your CV only goes to the AI you use (like Claude), nowhere else. No tracking.
- **Read every CV before you send it.** It's told to reword, never invent, and it checks numbers, but you're the final check.
- **The tool is free (MIT). The AI isn't:** you need a Claude plan or another AI you already pay for. (The repo has a guide for cheaper and local models.)
- It's a helper, not a job guarantee. Results depend on you and the jobs you pick.
