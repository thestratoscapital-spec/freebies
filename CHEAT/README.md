# 🎮 CHEAT: 3 GitHub repos that feel like a cheat code

You commented **CHEAT**. Here are all three repos from the video, what each one is, and the license (checked on GitHub on November 3, 2026).

| # | Repo | What it is | License |
|---|---|---|---|
| 1 | [**Lightpanda**](https://github.com/lightpanda-io/browser) | A headless browser built from scratch (in Zig) for AI agents and automation | ⚠️ AGPL-3.0 |
| 2 | [**The Book of Secret Knowledge**](https://github.com/trimstray/the-book-of-secret-knowledge) | A huge collection of manuals, cheat sheets, one-liners, and command-line and security tools | ✅ MIT |
| 3 | [**Public APIs**](https://github.com/public-apis/public-apis) | A community-built list of free APIs: weather, finance, games and much more | ✅ MIT |

---

## How to use each one

**Lightpanda: let your AI browse the web.** A headless browser has no window. Your code (or an AI agent) drives it to open pages, click and read. Start with the README's install steps, then ask Claude:

```
Read the Lightpanda README at github.com/lightpanda-io/browser and show me
the simplest way to open a page with it and read its text, step by step.
```

**The Book of Secret Knowledge: sharpen your toolkit.** It's a long reading list, not an app. Open it, use the table of contents, and bookmark the sections you need (command line, networking, security). Only use security tools on systems you own or have permission to test.

**Public APIs: building blocks for your next app.** Pick a category, open an API, check whether it needs a key and what its limits are. Then ask Claude:

```
I want to build [your idea]. Look at github.com/public-apis/public-apis and suggest
3 free APIs I could use, what each one gives me, and whether it needs an API key.
```

---

## ⚠️ The license note

- **MIT** (Book of Secret Knowledge, Public APIs): you can use them freely. Keep the original copyright notice if you copy their content.
- **AGPL-3.0** (Lightpanda): free to use, but if you change it and let people use your changed version **over the internet**, you have to share your source code under the same license. Read its LICENSE before you build a product on it.
- Each API listed in Public APIs has **its own terms**. Check them before you use one in a product.

This isn't legal advice. Licenses can change, so check the `LICENSE` file again before you launch.
